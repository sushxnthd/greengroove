01 / THE PROBLEMQueues are a systems problem.

THE QUESTION

What if a supermarket could respond to a queue before it becomes a queue?

A

Congestion is dynamic.

Checkout load changes minute by minute. Static lane assignment reacts late, after customers have already accumulated.

B

More hardware is not always the answer.

The project investigates whether lightweight sensing and better information can improve flow without simply adding more counters.

C

Efficiency can be sustainable.

Less idle infrastructure, smoother movement and better operational decisions connect customer experience with resource efficiency.

02 / THE SYSTEMSense → estimate → guide.

A small feedback loop
for a busy physical space.

Green Groove treats checkout flow as a real-time estimation problem. Signals from the store are converted into an interpretable congestion state, then used to recommend the least-loaded path.

01 · SENSE

Observe occupancy

Collect lightweight signals that approximate where demand is building.

02 · ESTIMATE

Score congestion

Translate noisy observations into a comparable state for each checkout.

03 / RESEARCHBuilt to be tested, not merely pitched.

RESEARCH FRAME

From a simple frustration to a measurable systems question.

The project reframes supermarket waiting time as a feedback-control problem: detect a changing state, estimate load, communicate an action and measure whether the intervention improves flow.

01

Observe

Map the variables that affect checkout load and identify signals that can be sensed at low cost.

02

Model

Represent counter-level congestion in a form that allows fast comparison between lanes.

03

Intervene

Generate a simple routing recommendation instead of hiding the decision inside an opaque score.

04

Evaluate

Compare waiting, throughput and system behavior under different arrival patterns and constraints.

CORE RESEARCH QUESTION

Can low-cost, real-time IoT signals reduce queue inefficiency in supermarkets without requiring proportionally more checkout infrastructure?
