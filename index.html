01PROJECT IN ONE LINE

Green Groove distributes checkout across the shopping journey instead of leaving it all to the counter.

The project links a shopper identity, shelf-level sensing and a continuously updated digital cart. The aim is not simply a faster checkout lane; it is a different transaction model.

It began as a product-design exploration and evolved into a broader systems problem involving sensing, state, identity, failure cases and human interaction.

02THE PROBLEM

Supermarkets already observe the action that matters: an item leaving the shelf.

Conventional checkout largely ignores that event and identifies the same product again later. Green Groove asks whether the transaction can be built progressively from the physical actions that happen during shopping.

01

Late identification

Item identity is operationally useful only at the end of the trip.

02

Disconnected state

Shelf movement, shopper identity and billing live in separate parts of the system.

03

Queue concentration

Too much transaction work is concentrated at one physical bottleneck.

04ENGINEERING DECISIONS

The hard part was never one device. It was preserving one coherent state.

That shifted the project from “design a smart shelf” toward “design a distributed physical-digital system.”

A

Persistent identity

A shopper needs one stable session identity across the trip.

WHY IT MATTERS / avoids reconstructing identity at checkout
B

Sense at the source

The shelf is where product state changes first become observable.

WHY IT MATTERS / reduces delay between physical and digital state
C

Continuous cart logic

The cart is treated as live state, not an end-of-trip receipt.

WHY IT MATTERS / billing becomes incremental rather than reconstructive
D

Inverse events

Putting an item back must reverse the state change created by picking it up.

WHY IT MATTERS / a real system must model returns, not only removals

07WHAT I LEARNED
“The project stopped being about a smart object when I realized the real design problem was keeping multiple states synchronized.”

Green Groove made me think beyond screens and objects. It forced me to reason about state transitions, sensing uncertainty, human behavior and how a physical action becomes trusted digital information.

That systems perspective became more valuable than the original branding exercise: the user experience is only as good as the invisible logic underneath it.
